Features

Everything a downloader should be

Clean, focused, and fast. Built as a Manifest V3 extension with a restrained, native-feeling UI.

Any quality, any container

Pick 4K down to 360p, or a clean audio track. MP4, WebM and M4A containers with one-click MP3 conversion via in-page FFmpeg WASM.

Playlists & batches

Drop a playlist link, browse every track, download individually, or send the whole list to a background batch queue.

Save for later

Bookmark videos you want to revisit and reopen them any time from the Saved tab, even after closing the popup.

Download history

Every download is recorded with its format and time. Reopen the video or clear the log whenever you like.

Private by design

No backend, no analytics, no account. Streams are fetched and transcoded on your machine; state lives only in local browser storage.

Live progress

A thin progress bar and status stay visible no matter which tab of the popup you are on, so a running download never hides.

Install

Up and running in a minute

The easiest path is the Chrome Web Store. Prefer to run from source? Three steps:

Clone & build

git clone this repo, then npm install and npm run build. Node 20.19+ required.

Load unpacked

Open chrome://extensions, enable Developer mode, and choose Load unpacked on the dist/ folder.

Pin it

Click the puzzle icon in your toolbar, pin Bit Downloader, and paste a YouTube link to go.

FAQ

Questions

Is this legal? / ToS?

Downloading may violate YouTube’s Terms of Service. Please only save content you have rights to, and respect platform rules. The tool is provided for personal archival and research.

Where do downloads go?

Straight to Chrome’s Downloads using its built-in manager — no custom folders, no hidden storage.

Why did a download stop working?

YouTube changes its internals without notice. If resolution breaks, updates are typically needed; that is true of every YouTube downloader. History and bookmarks survive restarts and updates.
