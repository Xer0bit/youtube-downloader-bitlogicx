Install · 60 seconds

Yours in three little steps

Because the Chrome Web Store doesn't allow YouTube downloaders, Bit Downloader is released straight from GitHub. It takes about a minute — and stays exactly as easy to update.

Grab the package

Download bit-downloader-v1.0.1.zip from the button below and unzip it anywhere.

Flip on dev mode

Open chrome://extensions and switch Developer mode on in the top corner.

Load unpacked

Hit Load unpacked, pick the unzipped folder — and pin Bit Downloader to your toolbar.

Questions

Fair questions

Why isn't this on the Chrome Web Store?+
Google's store policy prohibits extensions that facilitate downloading YouTube content, so Bit Downloader is released directly from GitHub instead. That means no store review queue, and updates whenever you want them.
Is it really free and private?+
Really. No accounts, no analytics, no backend. Downloads and MP3 conversion happen on your device; bookmarks and history live only in your browser's local storage.
Is downloading allowed?+
Please respect copyright and only save content you have the rights to keep. Downloading may conflict with YouTube's Terms of Service, so keep Bit Downloader for videos you own or are allowed to store.
It stopped working — now what?+
YouTube changes its internals regularly. When that happens, downloads can fail until an update lands. Watch the GitHub repo for the next release — it's usually quick.
Will you support Firefox?+
A Firefox port is planned. The offscreen-document architecture needs rework for Firefox's event pages before the MP3 converter can move over — star the repo to hear when it's ready.
