# Bit Downloader — v1.0.1

Self-hosted release of the Bit Downloader extension (Manifest V3).

> **Why self-hosted?** The Chrome Web Store rejected this category of extension
> (YouTube media downloaders) under its "prohibited products / copyrighted
> media" policy. This release is distributed directly from GitHub instead —
> install it yourself in under a minute. No store, no review queue, no account
> risk.

## What's in this release

- **`bit-downloader-v1.0.1.zip`** — the built extension package. Unzip it and
  load the folder as an unpacked extension.
- **`bit-downloader-v1.0.1.crx`** — signed CRX for developer-mode drag-and-drop
  install (same build).

## What changed since v1.0.0

- Removed the dormant sandboxed code evaluator (unsafe-eval surface) to keep
  the package policy-clean.
- Rebranded package to **Bit Downloader**.
- Version bumped to 1.0.1.

## Install (2 ways)

### A. Load unpacked (recommended, any Chromium)

1. Download `bit-downloader-v1.0.1.zip` and unzip it anywhere.
2. Open `chrome://extensions`.
3. Toggle **Developer mode** (top-right).
4. Click **Load unpacked** and select the unzipped folder.

### B. Developer-mode CRX drag-and-drop

1. Open `chrome://extensions` and enable **Developer mode**.
2. Drag `bit-downloader-v1.0.1.crx` onto the page and accept the prompt.

## Features

- Download YouTube videos in any quality (MP4 / WebM / M4A)
- Convert to MP3 locally via FFmpeg WASM (no uploads)
- Playlist resolution + background batch downloads
- Save-for-later bookmarks and full download history
- Live download progress across all views
- 100% local: no servers, no accounts, no analytics

## Privacy

All processing happens on-device. The extension contacts only
`youtube.com` / `googlevideo.com` endpoints needed to resolve and fetch the
media you request. Bookmarks, history and job state stay in
`chrome.storage.local`.
